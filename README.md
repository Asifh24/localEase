# LocalEase — Local Service Finder

A responsive React + Vite hackathon prototype for discovering local service providers.

## Run it locally

1. Install **Node.js LTS** from https://nodejs.org/ if you do not already have it.
2. Extract this ZIP folder.
3. Open the extracted `localease-starter` folder in VS Code.
4. Open **Terminal → New Terminal** in VS Code.
5. Run these commands one by one:

```bash
npm install
npm run dev
```

6. Open the local URL shown in the terminal (usually `http://localhost:5173`).

## Features included

- Responsive landing page inspired by the provided reference layout
- Service cards and service filtering
- Search by service and area text
- Provider cards with sample ratings, prices and availability
- Sorting by rating or lowest price
- Provider profile modal
- Demo booking form with confirmation state
- Mobile navigation

## Important

This is a front-end hackathon prototype. Provider profiles, ratings, prices and availability are sample data. The booking form does not save data to a server or contact real providers. To make it production-ready, connect a backend/database and real provider data.
